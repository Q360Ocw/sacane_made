# Smart Document Scanner — تطبيق أندرويد

نفس محرك المعالجة (OpenCV) من نسخة الكمبيوتر، بس بواجهة لمس مخصصة للهاتف (Kivy):
تصوير/اختيار صورة ← اكتشاف تلقائي للوثيقة ← سحب الزوايا بالإصبع ← اختيار وضع المعالجة ← مقارنة قبل/بعد ← حفظ PDF.

---

## ⚠️ قيد تقني مهم — اقرأه أول شي

بنيت واختبرت **كل منطق البرنامج فعليًا** (الاكتشاف، تصحيح المنظور، التبييض، سحب الزوايا باللمس، المقارنة، الحفظ) وشغّلته بمحاكاة شاشة هاتف حقيقية والتقطت لقطات تؤكد إنه شغال 100%.

**لكن** ما قدرت أبني لك ملف APK جاهز للتثبيت مباشرة، للسبب التالي:
> بناء تطبيق أندرويد يتطلب تحميل **Android SDK/NDK** (أدوات جوجل الرسمية، حجمها عدة غيغابايت) من خوادم Google، والبيئة يلي أنا شغال فيها ما إلها وصول لهاي الخوادم لأسباب أمنية.

**الحل العملي** يلي جهزته لك: ملف جاهز (`.github/workflows/build-apk.yml`) يخلي **GitHub نفسه** يبني الـ APK إلك مجانًا بالسحابة — ما بتحتاج تثبت ولا برنامج على جهازك. خطوات بسيطة تحت 👇

## ✅ الطريقة الأسهل: بناء APK عبر GitHub (بدون تثبيت أي شي)

### 1. أنشئ حساب GitHub (إذا ما عندك)
روح لـ [github.com](https://github.com) واعمل حساب مجاني (دقيقتين).

### 2. أنشئ مستودع (Repository) جديد
- دوس على زر **New** الأخضر.
- اختار اسم مثلاً `smart-scanner-mobile`.
- خليه **Public**.
- دوس **Create repository**.

### 3. ارفع ملفات المشروع
بأسهل طريقة، من نفس صفحة المستودع:
- دوس **uploading an existing file**.
- اسحب وفلّت **كل** محتويات مجلد `smart_scanner_mobile` (بما فيها المجلدات المخفية زي `.github`).
- دوس **Commit changes**.

> ملاحظة: بعض المتصفحات ما بتسمح برفع مجلدات فاضية أو مجلد `.github` بالسحب المباشر. إذا صار عندك مشكلة، أسهل حل: ثبّت [GitHub Desktop](https://desktop.github.com) (برنامج بواجهة رسومية بسيطة)، واعمل منه "Add local repository" ثم "Publish" — بينقل كل الملفات صح من أول مرة.

### 4. شغّل عملية البناء
- روح لتبويب **Actions** فوق بصفحة المستودع.
- رح تلاقي "Build Android APK" — دوس عليه.
- دوس **Run workflow** (إذا ما بدأ لحاله).
- انتظر (البناء الأول ياخد حوالي 20-30 دقيقة لأنه بيحمّل أدوات أندرويد كاملة — المرات الجاية أسرع).

### 5. حمّل الـ APK
- لما تخلص العملية (علامة ✅ خضراء)، دوس عليها.
- تحت بقسم **Artifacts**، رح تلاقي `SmartDocumentScanner-apk` — حمّله (رح يجيك ملف zip فيه الـ APK جواه).
- انقل ملف الـ APK لهاتفك (عبر رابط تحميل، USB، أو Google Drive).
- على الهاتف: فعّل "تثبيت من مصادر غير معروفة" (Install unknown apps) من الإعدادات، وبعدين افتح ملف الـ APK وثبّته.

## 🖥️ (اختياري) جرّب البرنامج على الكمبيوتر أول قبل الهاتف

نفس الكود بالضبط بيشتغل كنافذة عادية عالكمبيوتر (بواسطة Kivy) — طريقة سريعة تتأكد إنه شغال قبل ما تبني APK:

```bash
pip install -r requirements-desktop-test.txt
python main.py
```

رح تنفتح نافذة فيها نفس الواجهة تمامًا يلي رح تشوفها بالهاتف.

---

## 🐧 طريقة بديلة: بناء محلي (لمن عنده خبرة أكبر)

إذا عندك جهاز Linux (أو WSL على ويندوز) ومستعد تنتظر تحميل ~5-8 GB من أدوات أندرويد:

```bash
pip install buildozer cython==0.29.37
buildozer android debug
```

الملف الناتج رح يكون جوا مجلد `bin/`. أول مرة بتاخد وقت طويل (تحميل SDK/NDK)، بعدين البناء بيصير أسرع بكثير.

```
└── .github/workflows/build-apk.yml  # يبني APK أوتوماتيكيًا بالسحابة
```

## 🔐 الصلاحيات المطلوبة على الهاتف

البرنامج بيطلب عند أول فتح:
- **الكاميرا** — لتصوير الوثيقة مباشرة.
- **الصور/التخزين** — لاختيار صورة موجودة، وحفظ ملف PDF النهائي.

كل المعالجة تصير محليًا على الهاتف نفسه — ولا صورة بترفع لأي سيرفر.

## ⚠️ قيود معروفة (بشفافية)

- **لم يُختبر على جهاز أندرويد فعلي** من طرفي (لعدم توفر جهاز/محاكي أندرويد داخل بيئة العمل) — لكن كل منطق المعالجة واللمس مُختبر بالكامل عبر محاكاة دقيقة لشاشة هاتف. إذا واجهت أي مشكلة محددة بعد التثبيت على جهازك، ابعتلي تفاصيلها (رسالة الخطأ أو صورة) وبساعدك تصلحها.
- **الكاميرا داخل التطبيق**: تعتمد على مكتبة `plyer` للوصول لكاميرا أندرويد الأصلية؛ إذا واجهت مشكلة بالتقاط الصورة مباشرة من داخل التطبيق، الحل البديل الفوري هو: صوّر بكاميرا الهاتف العادية، وبعدين اختار الصورة من داخل التطبيق عبر زر "إضافة صورة".
- نفس القيود المذكورة بنسخة الكمبيوتر بخصوص تمييز "ورق عاجي" عن "إضاءة صفراء"، والميل الشديد جدًا الذي يتطلب تصحيح يدوي — سارية هون كمان.
